# 电商用户转化分析报告

> 数据：阿里天池 UserBehavior（淘宝用户行为）｜ 999,530 条行为记录 ｜ 9,739 名活跃用户 ｜ 2017-11-25 ~ 12-03（9 天，覆盖双 12 预热期）

---

## 一、报告摘要

**这份报告回答四个问题：谁在买、怎么买、什么时候买、能不能预测。**

**1）有 2,021 人「加购了但没买」—— 这是全平台价值最高的一块可运营人群。**

加购渗透率 75.2%，比购买渗透率 68.7% 还高。也就是说，有 2,021 人主动把商品放进了购物车，9 天里却一单没下。他们平均加购 6.1 次、浏览 81.6 次——不是"随手一点"，而是认真挑过却没转化。

**2）老客和新客是「两种模式」，差距是碾压级的。**

老客复购时 **39.99%** 是「不浏览、不收藏、不加购，直接下单」；新客首购的零间隙率只有 **3.27%**——差 **12 倍**。同样成交一单，高频买家平均浏览 18 次，低频买家 58 次，差 40 次。**说明老客靠惯性，新客靠比较，运营动作不该是同一套。**

**3）行为数据能预测的部分很有限——但圈人是有效的。**

用大促前 7 天行为预测后 2 天是否购买，模型 AUC **0.5862**，只比「直接看一个特征：观测窗内买过几次」高 0.007。9 个特征里，真正起作用的只有「用户有没有购买历史」。但把模型用于圈人，**命中率能比随机发券高 44%**。

> 注意：这是**关联性**结论，不是因果——「发券是否会让用户增加购买这一行为」需要 A/B 实验验证。

---

## 二、业务背景与数据说明

**行业场景**：电商平台，双 12 大促预热期。核心业务问题——**在预算有限的定向触达中，资源应该投给谁、投什么动作。**

**数据概况**

| 项 | 值 |
| :--- | :--- |
| 数据来源 | 阿里天池 UserBehavior（公开数据集） |
| 行为记录 | 999,530 条（pv 895,636 / cart 55,447 / fav 28,088 / buy 20,359） |
| 活跃用户 | 9,739 人 |
| 时间范围 | 2017-11-25 ~ 12-03（9 天） |
| 行为类型 | 浏览（pv）、收藏（fav）、加购（cart）、购买（buy） |

**⚠️ 一条必须写在最前面的边界**

本数据是**观测性快照**——没有随机分流、没有干预、没有对照组。因此：

- 本报告所有结论都是「**关联性**」，不是「因果性」
- 任何"提升 X%""预计收益 Y"的表述，都超出这份数据能支撑的范围
- 要验证"某个动作是否有效"，必须另做 A/B 实验

## 三、核心发现

### 组 A｜用户是谁

#### A1. 这是一个「多样性寻购」平台，不是「补货型」平台

**发现**：用户回来复购，几乎全是买**新东西**——换品复购 : 同品复购 ≈ **12 : 1**（12,650 次 vs 1,020 次），同品复购仅占购买事件的 5%。

**含义**：平台的增长杠杆是**交叉销售与推荐**（帮用户发现新品类、新商品），而不是补货提醒、订阅购买。用"日用快消"的运营思路（提醒你该囤货了）在这是无效的。

#### A2. 老客 vs 新客是两种模式（效应量碾压级）

**发现**：假设检验给出三个效应量，排序一目了然——

| 假设 | 对比 | 效应量 | 强度 |
| :--- | :--- | ---: | :--- |
| H2 老客 vs 新客的**零间隙率** | 39.99% vs 3.27% | Cohen's h = **−1.005** | **超大** |
| H3 高频 vs 低频的**每单浏览** | 18 次 vs 58 次 | Cliff's δ = **−0.651** | 大 |
| H1 加购 vs 未加购的**购买率** | 72.40% vs 57.41% | Cohen's h = **0.316** | 中等 |

**含义**：真正把用户区分开的，**不是「加不加购」，而是「是不是老客」**。老客决策路径极短（直接回购），新客需要完整比较（平均要逛 40 次才成交）。两者的运营动作完全不同。

### 组 B｜用户怎么买

#### B1. 购买路径以「直接买」为主——加购和收藏都不是必经环节

**发现**：20,359 次购买里，**83% 不经过加购**；含收藏环节的路径仅 **6.5%**。

**含义**：教科书式的「浏览 → 加购 → 购买」漏斗在这个平台**不成立**。优化重点应放在**详情页 → 直接转化**，而不是过度依赖购物车召回、收藏夹营销。

#### B2. 加购是「高意向未完成」的关键节点，2,021 人卡在这里

**发现**：

- 加购渗透率 **75.2%**（7,323 人）> 购买渗透率 **68.7%**（6,689 人）
- **2,021 人加购了但 9 天内一单没下**，平均加购 6.1 次、浏览 81.6 次
- 在四类行为里，**加购是唯一对购买有正向关联的**（Lift = 1.12）

**含义**：这 2,021 人已经用行动表达了购买意向，却卡在最后一步。**这是全平台召回价值最高、动作最明确的一块人群。**

### 组 C｜什么时候买 ≠ 能不能预测

#### C1. 晚间是流量高峰，但白天的转化效率更高

**发现**：全天行为量在 **21:00–22:00** 达峰（83,231 / 83,327 条）；但看购买行为，**10:00–16:00 时段的 buy 量能达到其峰值的 91%，而 pv 只有 60%**。

**含义**：**流量高峰 ≠ 转化高峰**。曝光类资源（推荐位、直播、push）应投晚间；转化类动作（发券、秒杀、定向优惠）反而适合白天——那时用户在"比价决策"状态，而非"刷着玩"。

#### C2. 行为数据能预测的部分很有限

**发现**：构造 9 个特征（浏览/收藏/加购/购买次数、活跃天数、近期性、广度、转化率）训练模型，结果：

- 测试集 AUC = **0.5862**，刚过及格线 0.579（"直接看最强单特征"的水平）
- 三个模型对比，**逻辑回归胜出**——两个树模型（随机森林、XGBoost）都因过拟合而落后
- 特征重要性显示：**9 个特征里只有「购买历史」真正起作用**（`obs_buy_cnt` 系数是其余特征的 3~45 倍）
- 但按预算取 Top10% 圈人，**命中率比随机发券高 44%**（Lift = 1.44）

**含义**：光靠行为日志，"预测谁会不会买"只能做到这个程度——因为购买还受价格、需求、时机等**数据里看不到的因素**影响。**但模型的排序能力仍然有用**：它不能告诉你"谁一定会买"，但能告诉你"优先触达谁"。

## 四、策略建议与优先级

| 优先级 | 策略 | 依据 | 具体动作 |
| :--- | :--- | :--- | :--- |
| **P0** | **召回「加购未购买」的 2,021 人** | B2 | 购物车提醒、待结算商品推送、加购商品降价通知 |
| **P1** | **分人群运营：新客与老客用两套动作** | A2 | 新客：优化搜索/推荐/榜单、首单优惠、降低试错门槛<br>老客：一键复购、常购清单、会员日回购权益 |
| **P1** | **强化交叉销售与推荐** | A1 | 跨品类关联推荐、新品类曝光——而不是补货提醒 |
| **P2** | **按"流量/转化"错峰分配资源** | C1 | 曝光类投晚间 20–23 点；转化类动作投白天 10–16 点 |
| **P2** | **建立 A/B 实验体系** | C2 | 上述动作落地前，随机分组留对照，用实验数据验证真实增量 |

**⚠️ 关于"预期收益"的说明**

上表只给**优先级**，不给"预计提升 X%"——因为本数据没有实验对照，任何量化收益承诺都是不负责任的。**P0/P1/P2 的排序依据是"发现的证据强度 × 动作的可执行性"，不是收益测算。**

## 五、局限与下一步

**四条局限**

1. **观测性数据，无因果结论**。所有发现都是"两件事相关"，不是"一件事导致另一件事"。
2. **窗口仅 9 天，且在大促预热期**。用户行为受双 12 影响，结论外推到常规周期需重新验证。
3. **左删失**。11/25 之前的行为不可见，新客的"首次购买前路径"可能被低估。
4. **无金额字段**。数据不含价格、订单金额、利润，因此**无法计算 ROI、客单价或毛利**——所有建议都是"行为层面"的，不是"财务层面"的。

**下一步**

1. **对 P0/P1 动作做 A/B 实验**：随机分组、留对照组，验证"触达是否带来真实增量"（而不是只看被触达人群的表现）
2. **补充埋点**：价格、优惠券、渠道来源、退款状态——这些字段能显著提升模型预测力
3. **拉长观察窗口**：覆盖完整的大促周期 + 平销期，验证结论的稳定性

## 附录：分析方法与口径

| 章节 | 方法 | 关键口径 |
| :--- | :--- | :--- |
| EDA | 分布分析、异常审查 | 头部 30 用户占行为 1.7%，不剔除 |
| 时间分析 | 日/小时粒度趋势 | 北京时间 UTC+8 |
| 商品分析 | 集中度（CR1/CR5/HHI）、阈值敏感性 | 转化率样本阈值 ≥ 50 人浏览 |
| 路径分析 | 有序路径提取、耗时统计 | 区分「用户级跨商品」与「商品级单商品」两套口径 |
| 漏斗分析 | 并行渗透率 + 有序流转率 | 渗透率去重人数口径；流转率要求时序 |
| 用户分层 | R × F 九层（弃用 M） | M 与 F 高度共线（ρ=0.985）故剔除 |
| 假设检验 | 两比例 Z 检验、Mann-Whitney U | 效应量为主（Cohen's h / Cliff's δ），p 值仅参考 |
| 预测建模 | 逻辑回归 / 随机森林 / XGBoost | 观察窗 7 天 → 预测窗 2 天；以 AUC + Lift 评估 |
